# 06 法律与社会规则

> 这一篇解决一个问题：**遇到事的时候，去哪查、找谁、留什么证据。**
>
> 核验日期：2026-11　｜　上一篇：[[05-金钱与经济]]
>
> **本篇不构成法律意见。** 只告诉你去哪查、怎么留证据。具体案子请咨询律师或法律援助机构。

## 一、普通人最可能用到的四类

### 1. 劳动合同

入职前后最该确认的七件事：

| 项 | 为什么重要 |
| --- | --- |
| 书面合同 | 没有书面合同，维权时举证极难；超过一个月不签，单位要付双倍工资 |
| 试用期时长 | 三年以上合同试用期最多六个月，且只能约定一次 |
| 工资构成 | 基本工资、绩效、补贴分开写，裁员赔偿按"应得工资"算 |
| 社保公积金 | 入职当月就该缴，不缴是违法，不是"福利" |
| 工作时间 | 标准工时、综合工时、不定时，三种算法差别很大 |
| 竞业限制 | 有竞业就必须有补偿，没补偿的竞业条款通常无效 |
| 离职条款 | 提前三十天书面通知即可，单位不能扣押证件和档案 |

**必须留的证据**：劳动合同原件、工资流水、考勤记录、工作沟通记录（企业微信、邮件）、社保缴纳记录。

### 2. 租房

四件事：押金、维修责任、提前退租、转租。

| 坑 | 怎么防 |
| --- | --- |
| 押金不退 | 合同写明退还条件和时限；交房时拍照录像，双方签字 |
| 家电坏了谁修 | 合同写明"自然损耗由房东维修" |
| 提前退租扣押金 | 合同写明违约金上限，一般不超过一个月租金 |
| 二房东跑路 | 要求看房产证或房东授权书，租金打给产权人 |

**关键动作**：入住当天把所有瑕疵拍照，发给房东并留存聊天记录。退房时同样拍一遍。

### 3. 消费维权

顺序是：**协商 → 投诉 → 起诉**。

| 步骤 | 找谁 | 时效 |
| --- | --- | --- |
| 协商 | 商家 | 越早越好 |
| 投诉 | 12315（市场监管）、12345（政务服务） | 一般一年内 |
| 起诉 | 法院，小额诉讼程序 | 三年诉讼时效 |

**网购七日无理由退货**：除定制品、生鲜、拆封的数字化商品等，其他都可以。商家说"不支持"不等于法律不支持。

### 4. 个人信息

哪些事你有权拒绝：

- 商家无权因为你不给手机号就不提供服务（除非业务必需）
- 人脸识别不能作为唯一验证方式
- 你有权要求删除自己的个人信息
- 营销电话和短信可以要求停止

**依据**：《个人信息保护法》。查原文的方法见下一节。

## 二、怎么查法条

三个入口，按顺序用：

1. **国家法律法规数据库**（flk.npc.gov.cn）：法律、行政法规、地方性法规的官方原文。**这是唯一权威入口。**
2. **最高人民法院官网**：司法解释和指导案例。
3. **中国裁判文书网**：类似案子法院怎么判的。看判决理由，不看结论。

**查法条的三个技巧**：

- 先找"法律"再找"条例"，法律效力高
- 注意"施行日期"，旧版可能已废止
- 看"但书"（"但是……"后面的内容），例外往往藏在那里

## 三、常见说法，哪些靠不住

| 说法 | 判断 | 为什么 |
| --- | --- | --- |
| 试用期可以随便辞退 | 错 | 试用期辞退也要有法定理由，且要说明 |
| 主动辞职没有补偿 | 一般对 | 但因单位违法（欠薪、不缴社保）被迫离职的，可以要经济补偿 |
| 口头承诺也算数 | 部分对 | 法律上算，但举证极难，所以要落到书面 |
| 签了字就不能反悔 | 错 | 显失公平、欺诈、胁迫签订的可以撤销 |
| 打官司很贵 | 不一定 | 小额诉讼费用低，劳动争议仲裁不收费 |
| 劳动仲裁很麻烦 | 相对简单 | 不收费，流程比诉讼短，是劳动争议的前置程序 |

## 四、遇到事的第一反应

按这个顺序，别跳步：

1. **别签任何你没看懂的东西。** 尤其是"自愿放弃""已结清"这类字眼。
2. **留证据。** 聊天记录、录音（自己参与的对话可以录）、转账凭证、书面通知。
3. **写时间线。** 什么时候发生什么，越具体越好。这决定了你后面能不能讲清楚。
4. **查法条。** 先确认自己占不占理，再决定要不要争。
5. **找对渠道。** 劳动争议找仲裁，消费找 12315，人身损害找法院。

## 六、这一篇的边界

- **不给具体案件的意见。** 每个案子的事实细节不同，通用建议可能害了你。
- 不讨论法律是否合理。这一篇只解决"怎么办"。
- 不覆盖刑事、婚姻、继承等复杂领域。那些必须找专业律师。

## 七、三条最实用的提醒

1. **书面优先。** 口头约定在法庭上等于没有。
2. **时效别忘。** 劳动仲裁一年，民事三年，过了就丧失胜诉权。
3. **免费渠道是存在的。** 12348 法律咨询、法律援助中心、工会，很多人不知道。
