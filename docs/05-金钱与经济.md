# 05 金钱与经济

> 这一篇解决一个问题：**和个人有关的几个经济概念，以及哪些"理财建议"其实是在卖东西。**
>
> 核验日期：2026-11　｜　上一篇：[[04-身体与营养]]
>
> **本篇不构成投资建议。** 只讲概念和判断方法，不推荐任何产品。

## 一、四个必须先懂的概念

### 1. 通货膨胀：钱放着会变少

不是"物价涨了"，是"同样的钱能买的东西变少了"。

假设每年通胀 3%，100 块放十年不动，购买力大约剩 74 块。这意味着：**现金不是"安全"，只是"慢速亏损"。**

这也解释了为什么"存钱"本身不是目标，保值才是。

### 2. 复利：时间比收益率更重要

本金 1 万，年化 7%：

| 年限 | 金额 |
| --- | --- |
| 10 年 | 约 1.97 万 |
| 20 年 | 约 3.87 万 |
| 30 年 | 约 7.61 万 |

**关键在"年限"这一列，不在收益率。** 所以对年轻人来说，早开始比找高收益重要得多。

反过来也成立：**负债的复利一样可怕。** 信用卡分期年化常在 15% 以上，房贷之外的消费贷要特别小心。

### 3. 流动性：急用钱时能不能拿出来

| 资产 | 流动性 | 说明 |
| --- | --- | --- |
| 活期存款 | 最高 | 随时取 |
| 货币基金 | 高 | 一般当天或次日 |
| 定期存款 | 中 | 提前取损失利息 |
| 股票基金 | 中 | 卖出到账有几天，且可能正在跌 |
| 房产 | 最低 | 几个月卖不掉是常事 |

**规则：三到六个月的生活费必须放在高流动性资产里。** 这笔钱不追求收益，追求"随时能用"。

### 4. 风险与收益：没有例外

**任何承诺"高收益低风险"的东西，要么是骗局，要么风险你没看见。**

这句话没有反例。看到"保本高息""稳赚不赔""内部渠道"，先假设是骗局，再去找证据推翻这个假设。

## 二、最该防的四个坑

### 1. 收益承诺

正规金融产品不能承诺保本保收益（除了存款和国债这类）。凡是开口就说"年化 15% 保本"的，基本可以断定有问题。

### 2. 不懂就投

"别人都在买""错过了就没了"——这类话术针对的是怕错过，不是理性判断。

**规则：说不清它靠什么赚钱，就不投。**

### 3. 借钱消费

消费贷、分期、白条，年化利率往往在 15% 到 24% 之间。买一件 5000 块的东西分 12 期，实际多付的钱比你感觉的多。

**算法**：把所有手续费加起来，除以本金，再按实际占用时间折算年化。多数人会算完就放弃分期。

### 4. 保险买错

保险的作用是**转移无法承受的风险**，不是理财。

| 该买 | 不该买 |
| --- | --- |
| 医保（基础） | 返还型、分红型（贵且收益低） |
| 百万医疗（大病住院） | 万能险当储蓄 |
| 意外险（便宜，杠杆高） | 给孩子买寿险 |
| 定期寿险（有房贷/家庭责任时） | 先给小孩买、大人裸奔 |

**顺序：先保大人，再保小孩；先保大病，再谈理财。**

## 三、几个容易搞混的概念

| 概念 | 不是 | 是 |
| --- | --- | --- |
| 资产 | 你赚多少 | 你拥有什么（能带来现金流的东西） |
| 负债 | 你花多少 | 你要还什么（包括未来的固定支出） |
| 净资产 | 收入 | 资产减负债 |
| 财务自由 | 有很多钱 | 被动收入覆盖基本支出 |

最后一条尤其容易误解。**财务自由的关键是"支出"这个分母，不是"收入"这个分子。**

## 四、判断理财信息的五问

1. **它在卖什么？** 内容免费，那变现方式是什么。
2. **收益率怎么来的？** 说不清底层资产（钱拿去干什么了），就是说不清风险。
3. **有没有"保本高息"？** 有就是骗局。
4. **时间尺度多长？** 拿三年翻倍的案例讲复利，是选择性举例。
5. **亏了谁承担？** 推荐人不承担后果的建议，要打折听。

## 六、这一篇的边界

- **不推荐任何具体产品、平台、基金、股票。**
- 不预测市场。能准确预测的人不需要写文章。
- 不讨论"该不该买房"这类需要具体家庭情况的问题。

## 七、给普通人的四句话

1. **先有应急金，再谈投资。** 三到六个月生活费。
2. **还清高息负债，等于稳赚。** 还掉年化 18% 的分期，比找 18% 收益的投资容易得多。
3. **不懂不投。** 这条能避开九成的坑。
4. **时间是最好的杠杆。** 早开始十年，比多赚两个点重要。
