# 03 英语

> 这一篇解决一个问题：**英语到底值不值得普通人花时间，以及为什么大部分人学了十年还是不会。**
>
> 核验日期：2026-11　｜　上一篇：[[02-AI与数字工具]]

## 一、先说实话：值不值得

分两种情况，结论不一样。

**如果你的工作、生活完全用不到英文**，那它对你来说是"可能性"而不是"必需品"。花多少时间取决于你想要多少可能性。

**如果你要接触这些东西**，那英语是门槛，绕不过去：

| 你想做的事 | 英语的作用 |
| --- | --- |
| 学技术、学专业 | 一手资料八成是英文，中文资料平均滞后一到三年 |
| 了解国际新闻 | 同一件事，不同立场的中文报道差异很大，英文原文能对照 |
| 用国外课程和工具 | 大量优质资源没有中文版 |
| 出国、外企、远程工作 | 直接门槛 |

**关键不是"英语重要"，是"信息差"。** 同样一件事，你能读原文，你的判断就比只读二手的人准一档。

## 二、为什么大部分人学了十年还是不会

四个原因，每一个都很常见。

### 1. 只输入，不输出

看了很多视频、背了很多单词，但从来没说过一句完整的话，没写过一段完整的文字。

**语言是技能，不是知识。** 认识单词不等于会用，就像看过游泳教学不等于会游泳。

### 2. 用"背单词书"当主线

从 A 背到 Z，背到 abandon 就放弃了。就算背完，也不会用，因为单词脱离语境没有意义。

**单词应该在句子里学，不是列表里。**

### 3. 追求"学完"而不是"用起来"

买了很多课，开了很多头，没有一次走完。因为目标定成了"学完新概念四册"，而不是"能读懂一篇技术文档"。

**目标要具体到能验收。** "学完"没法验收，"能读懂"可以。

### 4. 没有间隔

今天学三小时，明天不学，后天学五小时。遗忘曲线不管你今天多努力，只看你多久没复习。

## 三、有效的四种做法

### 1. 每天固定时长，不断

比"周末突击五小时"有效得多。原因写在 [[07-学习方法]] 里：间隔比集中有效。

**30 分钟每天，好过 3 小时每周。**

### 2. 输入和输出各占一半

| 输入 | 输出 |
| --- | --- |
| 读文章、听播客、看剧 | 复述、写句子、跟读、说 |
| 目标：认识 | 目标：能用 |

只输入的人，读到第七年还是"看得懂但说不出"。

### 3. 用能验收的小目标

不好的目标：学完新概念第二册。
好的目标：能不看字幕听懂一段三分钟的新闻；能写一段 100 词、没有语法错误的自我介绍。

**验收标准要具体到"能做什么"，不是"学了什么"。**

### 4. 复述比重读有效

读完一段，合上原文，用自己的话说一遍。说不出来就是没读懂。

这一步很痛苦，但它是唯一能暴露"我以为我懂了"的方法。

## 四、几个常见说法，哪些靠不住

| 说法 | 判断 | 为什么 |
| --- | --- | --- |
| 看美剧能学英语 | 一半对 | 只看中文字幕等于看中文剧；要开英文字幕或关字幕 |
| 背完单词书就能读 | 错 | 阅读靠的是词组和句式，不是单词表 |
| 语感最重要，语法不用学 | 错 | 语感是大量输入后的结果，不是替代品；初期语法能省很多时间 |
| 全英文环境才能学好 | 不一定 | 环境能逼你输出，但输出可以自己造 |
| 一天背 100 个单词 | 效率低 | 记不住，且用不上；一天 20 个放进句子里更实在 |

## 五、一个能执行的最小方案

面向"想读懂英文资料"的普通人，不是面向考试。

| 时间 | 做什么 | 目的 |
| --- | --- | --- |
| 每天 20 分钟 | 精读一段（100 到 200 词），查生词，分析一个长句 | 打基础 |
| 每天 10 分钟 | 复述昨天那段，不看原文 | 检验 + 记忆 |
| 每周一次 | 写 100 词，主题自选 | 输出 |
| 每月一次 | 换一篇更难的材料 | 提升梯度 |

**关键在"每天"两个字，不在时长。**

## 七、这一篇的边界

- 不针对考试（四六级、雅思、托福），考试有它自己的技巧，和"会用英语"是两件事。
- 不推荐具体机构或课程。这类推荐和商业利益绑得太紧。
- 不给"三个月流利"的承诺。语言没有捷径，只有不断和不断。

## 八、给成年人的一句提醒

**不要从音标和语法书重新开始。** 你已经学过十年，缺的不是基础，是用起来的机会。

从"读一段真实的材料、说一句完整的话"开始，比从第一页开始有效。
