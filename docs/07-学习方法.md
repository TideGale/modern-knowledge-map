# 07 学习方法

> 这一篇解决一个问题：**为什么你学了很多遍还是不会，以及哪些"高效学习法"其实没用。**
>
> 核验日期：2026-11　｜　上一篇：[[06-法律与社会规则]]

## 一、一个残酷的事实

**你的学习感觉不准。**

研究里反复出现同一个现象：用"重读、划线、看讲解"学习的人，**自我感觉更好，实际记住的更少**；用"自测、回忆"学习的人，**过程很痛苦，实际记住的更多**。

这叫"流畅性错觉"（fluency illusion）。文字读得顺，你就以为懂了。

所以判断一种方法好不好，**不能靠"学的时候顺不顺畅"，要靠"一周后还能不能做出来"。**

## 二、四种真正有效的做法

### 1. 检索练习：合上书，自己回忆

比重读有效得多。这是教育心理学里最稳的结论之一。

| 做法 | 效果 |
| --- | --- |
| 读完再读一遍 | 低 |
| 读完划重点 | 低 |
| 读完合上书，写出刚才的内容 | **高** |
| 读完做题（不看答案） | **高** |

**原理**：回忆的过程本身在加固记忆。读只是"再看一次"，没有提取的动作。

**怎么用**：每学完一块内容，合上书，用自己的话写三句。写不出就是没懂。

### 2. 间隔：不要一次学太久

同样总时长，分散到多天比集中在一天记得牢。

| 安排 | 一周后记得 |
| --- | --- |
| 一天学 3 小时 | 少 |
| 每天 30 分钟，学六天 | **多** |

**理由**：遗忘发生在两次学习之间，而每次重新提取都要重新费力，这个"费力"就是加固。

**怎么用**：重要的内容，第一次学完，隔一天、隔三天、隔一周各回顾一次。

### 3. 交错：混着练，不要一次练一个

看起来违反直觉。练一个题型练到熟，当天测验成绩最好；但换成混合练习，**当天成绩差，一周后成绩好**。

原因是：交错练的不是"怎么做"，是"这是哪一种、该用哪个方法"。

**怎么用**：复习时不要按章节顺序，随机抽题。这样练的是辨别能力，不是熟练度。

### 4. 生成：自己先想，再看答案

直接看答案，你得到答案；先想一遍再看，你得到判断力。

这一条对用 AI 学习尤其重要。**先自己写，再让 AI 改，比让 AI 直接写给你有效十倍。**

## 三、四种看起来有效但没什么用的做法

| 做法 | 为什么无效 |
| --- | --- |
| 反复重读 | 熟悉感被误认为掌握 |
| 划重点、抄笔记 | 动作替代了思考，手在动脑子没动 |
| 看讲解视频 | 输入太舒服，没有提取，看完就忘 |
| 集中突击 | 短期有效，长期几乎全忘 |

**这四条的共同点：过程舒服。** 而舒服通常意味着没在费力，没费力就没加固。

## 四、怎么判断自己真的学会了

三个标准，从低到高：

| 层级 | 标准 | 检验方法 |
| --- | --- | --- |
| 1 | 能认出来 | 看到知道见过 |
| 2 | 能讲出来 | 不看资料，讲两分钟 |
| 3 | 能用出来 | 换个场景也能用，能改，能排错 |

**大部分学习停在第一层。** 而工作和考试要的是第二、第三层。

**最低成本的检验**：找一个不懂的人，讲给他听。讲不清的地方就是你没懂的地方。

## 五、一个能执行的日常结构

面向"下班后自学"的人，不是全日制学生。

| 时段 | 时长 | 做什么 |
| --- | --- | --- |
| 学新内容 | 40 到 60 分钟 | 一个主题，不切换 |
| 立即自测 | 10 分钟 | 合书回忆，写出要点 |
| 第二天开头 | 10 分钟 | 回忆昨天的内容，再进新的 |
| 每周一次 | 40 分钟 | 随机抽旧内容自测（交错） |
| 每月一次 | 1 小时 | 全量回顾，找出断层 |

**关键不是时长，是"每次都带提取动作"。**

## 六、几个常见误区

| 误区 | 实际情况 |
| --- | --- |
| 学得慢就是笨 | 慢往往是在真正加工；快而顺常常是没学进去 |
| 要一次学完 | 分段 + 间隔，比一次学完有效 |
| 懂了就会了 | 懂是输入，会是输出，中间差着练习 |
| 记不住就是没天赋 | 多数是方法问题，不是天赋问题 |
| 学习要心情好 | 心情好适合输入，提取练习本来就难受 |

## 八、这一篇的边界

- 不讲记忆术（记忆宫殿等）。那些对特定场景有效，但不是通用方法。
- 不承诺提分。学习方法能提高效率，不能替代时间投入。
- 不讨论天赋差异。这一篇只讲可控的部分。

## 九、如果只记一句话

**合上书，自己想一遍。**

这一个动作的效果，超过上面所有方法的组合。
