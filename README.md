# 现代知识地图

> 信息时代值得知道的事，给普通人的一份导航。

## 这不是什么

- **不是资源合集。** 那种东西 GitHub 上已经很多，多数三年后一半链接失效，也没人知道该信哪条。
- **不是推荐清单。** 推荐会过期，而清单不会告诉你什么时候过期。
- **不是教程。** 每篇讲的是判断方法和最低限度的常识，不追求把一门学问讲完。

## 这是什么

四个东西，按重要性排：

1. **判断方法。** 看到一个说法，怎么在五分钟内判断它值不值得信。
2. **最低限度的常识。** 每个领域里那几条最该知道的，不知道会吃亏的。
3. **有限入口。** 每个领域给 5 到 15 个一手来源，宁缺毋滥。
4. **维护机制。** 每个资源标核验日期，脚本定期查死链，失效的直接降级或删掉。

## 为什么做这个

网上不缺信息，缺的是两样东西：**知道该信谁**，和**知道该从哪开始**。

这两样恰好是学校不教、广告不会说、AI 说得很顺但经常编的。

这份导航不替你做决定，只做一件事：把"可靠的信息在哪、怎么判断、什么时候会过期"写清楚。

## 收录标准

四条硬标准，缺一条就不收：

| # | 标准 | 怎么判断 |
| --- | --- | --- |
| 1 | 一手或准一手 | 官方文件、原始研究、原作者维护的项目、权威机构发布 |
| 2 | 开放获取 | 免费可读，没有注册墙和付费墙 |
| 3 | 持续维护 | 网站看是否还在更新，项目看近一年有无提交 |
| 4 | 可追溯 | 转载必须注明来源，二手内容必须能追回一手 |

**明确不收**：聚合导航站、盗版资源站、单一作者的观点合集、AI 生成的资源列表、需要注册才能看的"免费"资源。

## 三条判断原则

1. **能自己验证的才能信。** 链接点一次，数字核一遍，代码跑一遍。不能验证的，标明未核实。
2. **降级使用比升级安全。** 拿不准是几手，按低一级用。
3. **没有核验日期的推荐等于没有推荐。** 你不知道它是什么时候还有效。

## 每篇的结构

统一按这个格式写，方便横向对比：

1. **这一篇解决什么问题**
2. **几条最该知道的**
3. **常见的错误说法**（标出为什么错）
4. **判断方法**
5. **去哪找一手信息**（带等级和核验日期）
6. **这一篇的边界**（说明什么不在范围内）

## 核验机制

每个资源条目必须带五个字段：

| 字段 | 说明 |
| --- | --- |
| 名称 | 官方名称，不用简称 |
| 地址 | 一级入口，不写深层链接 |
| 一句话 | 这个资源解决什么问题，不超过 25 字 |
| 等级 | A 官方原始 / B 开放教材 / C 社区线索 |
| 核验日期 | `YYYY-MM`，含义是"这个月我打开过，链接有效，范围没变" |

`scripts/check_links.py` 读 `data/resources.yml`，逐个请求，输出失效清单。建议每月跑一次。

```bash
python scripts/check_links.py              # 直接跑
python scripts/check_links.py --proxy http://127.0.0.1:7890   # 有代理时
```

脚本把结果分成四种，**只有 404 和 410 才算真的失效**：

| 状态 | 含义 | 要做什么 |
| --- | --- | --- |
| OK | 能访问，或有访问限制但站点还在 | 无 |
| TIMEOUT | 请求超时 | 换网络或用 `--proxy` 重跑 |
| UNREACHABLE | DNS 或连接失败 | 同上 |
| DEAD | 404、410 | 确认后删掉或换链接 |

**为什么要分开。** 这个仓库在国内网络环境维护，访问国外站点超时是常态。把它们算成失效会产生大量误报，项目立刻失去可信度。所以脚本宁可漏报，不可误报。

## 谁能用

- **刚上大学的人**：想知道哪些东西值得花时间学，哪些是浪费时间。
- **工作几年的人**：发现自己缺的不是努力，是判断力。
- **被网上的说法绕晕的人**：想知道怎么核实。
- **用 AI 用得多的人**：想知道哪些地方它会骗你。

## 关于它不做什么

- 不提供医疗、法律、投资的**具体建议**，只告诉你去哪查、怎么查。
- 不追求覆盖面，宁可少写。没有的篇目就是没写，不是遗漏。
- 不承诺更新频率，但承诺**每个链接都标了核验日期**。

## 免责声明

医疗、法律、投资类内容**只做信息导航，不构成专业建议**。

涉及具体决策时，请查官方原文或咨询持证专业人士。这个仓库的价值在于告诉你"去哪里查"，不在于替你判断。

## 关于维护

一个人维护，更新频率取决于实际使用。**不接受大批量资源提交**，只接受三类贡献：

1. 指出错误（事实错、链接失效、等级判断错）
2. 补充核验（你打开过某条资源，确认它还在）
3. 改进判断方法（有更好的验证流程）
